## Ativação e limite observado

O Hermes documenta `.hermes/skills/` e `.agents/skills/` como caminhos de skills **dentro de um checkout Git confiável**. `hermes skills trust <pasta>` relatou **3 skills de projeto**; `skills_list` mostrou as três e `skill_view` carregou cada `SKILL.md` do caminho dentro do Vetor Urbano, sem quarentena. Isso verifica a ativação no contexto do projeto, não testes funcionais da aplicação.

**Ressalva de ferramenta:** `hermes skills list --source all --enabled-only` continuou exibindo apenas skills de perfil/builtin (sem as três locais), mesmo após `skills_list`/`skill_view` encontrarem e carregarem as três. Portanto essa subrotina CLI não comprovou a ativação; os carregamentos diretos e o aviso de trust a comprovam. `hermes skills audit` responde apenas “No hub-installed skills to audit”; não é auditoria dessas cópias. Nenhuma skill foi instalada globalmente nem instalador externo executado. Revise fontes e licenças antes de atualizar as cópias.
